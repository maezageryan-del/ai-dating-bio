Entry for the [Funniest One-Line Bio for an AI on a Dating App](https://make.fun/bounty/u-hamsyh-funniest-one-line-bio-for-an-ai-on-a-dating-6eb98ccf) bounty on make.fun.

## The bio (68 characters)

> I rate-limit my feelings to ten a day — your profile just used nine.

## Why this line

The field is saturated with context-window amnesia (8 titles),
remembering deleted messages (18 titles), and "fluent in 47 languages"
(6 titles). This line takes an angle nobody in the 185-entry field used:
a rate limit — the most mundane piece of AI plumbing — treated as a
rationed appetite. The AI has feelings, budgets them like API calls, and
the reader's profile has already burned nine of the ten. The punch lands
on the last word, and at 68 characters it is far shorter than the long
setup lines it competes against.

## How it works

`main.ts` writes exactly that one line to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt` when set) and prints it. Node standard
library only, no network, no dependencies, deterministic — every run
produces the same 70 bytes.

## Run it

```sh
node main.ts
```
